# 什么是 Python

Python 是一种流行的编程语言，由 Guido van Rossum 于 1991 年创建。

Python 是一种易于学习且功能强大的编程语言。它具有高效的高级数据结构和一种简单但有效的面向对象编程方法。Python 优雅的语法和动态类型，以及其解释型特性，使其成为在大多数平台上进行脚本编写和快速应用程序开发的理想语言。

它可以用于：

- Web 开发（服务器端）
- 软件开发
- 数学计算
- 系统脚本编写

## Python 能做什么？

- Python 可以在服务器上用于创建 Web 应用程序。
- Python 可以与软件一起使用来创建工作流。
- Python 可以连接数据库系统，还可以读取和修改文件。
- Python 可以用于处理大数据并执行复杂的数学计算。
- Python 可以用于快速原型设计，或用于生产级软件开发。

## 为什么选择 Python？

- Python 可以在不同的平台上运行（Windows、Mac、Linux、Raspberry Pi 等）。
- Python 具有类似英语的简单语法。
- Python 的语法允许开发人员用比其他一些编程语言更少的代码行编写程序。
- Python 运行在解释器系统上，意味着代码一旦写好就可以立即执行，这使得原型设计非常快捷。
- Python 可以以过程式、面向对象或函数式的方式进行处理。

## 须知

- Python 最新的主要版本是 Python 3，我们将在本教程中使用它。然而，Python 2 虽然除了安全更新外不再更新，但仍然相当流行。
- 在本教程中，Python 将在文本编辑器中编写。也可以在集成开发环境（IDE）中编写 Python，例如 Thonny、Pycharm、Netbeans 或 Eclipse，这些工具在管理大量 Python 文件时特别有用。
